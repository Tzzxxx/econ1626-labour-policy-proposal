# Econ1626-labour-policy-proposal
# Generative AI and Australian Employment

Policy proposal for Jobs and Skills Australia

## Project overview

This repository contains a policy proposal on monitoring the effects of generative AI on employment in Australia. It considers how AI may affect jobs, tasks, wages and industries, and recommends a two-year monitoring pilot for Jobs and Skills Australia (JSA).

## Recommended policy

The proposal recommends that JSA run a two-year AI and Work Monitoring Pilot. The pilot would track changes in selected occupations and industries, using employment and vacancy data alongside measures of AI exposure and adoption. The aim is to help policymakers distinguish potential task exposure from observed labour-market changes.

## Scope

The proposal focuses on Australia and considers employment, tasks, wages, industry structure and distributional effects. It compares three policy options and sets out indicative costs, responsibilities, a timeline and performance measures for the recommended pilot.
